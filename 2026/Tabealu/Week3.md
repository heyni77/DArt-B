# 학습 내용 정리

## 20강: 파이와 도넛차트
<!-- 파이와 도넛차트에 관해 배우게 된 점을 적어주세요 -->
### 파이차트
```
- 전체에 대한 비율을 표시할 때 주로 사용
- 실제 값보다는 비율로 표시하는 것이 한 눈에 보기 좋음
```

### 도넛 차트
```
- 파이차트와 이중축을 활용하여 만들 수도 있음 
    - 열 부분을 두 번 클릭하여 임의의 축을 생성 > 이중축 클릭
```

> **🧞‍♀️ 도넛차트를 생성하는 법을 포함해주세요.**
- 생성된 파이차트에서 행 부분을 두 번 클릭하여 임의의 축(0입력)을 생성한다. 
- 임의의 축을 ctrl키를 누르며 우측으로 드래그 해 두 개를 생성한다.
- 오른쪽의 위치한 파이차트의 모든 값을 빼주고 레이블의 매출 값만 올려준다.
- 이후 오른 쪽 파이차트에서 이중축을 클릭하여 색 조정과 크기 조정을 해준다. 


## 21강: 워드와 버블차트
<!-- 워드와 버블차트에 관해 배우게 된 점을 적어주세요 -->
### 버블차트
```
- 수치적 데이터를 우너의 크기로 표현하는 차트
- 두 개의 요소를 함께 클릭하여 표현 방식에서 버블 차트 선택
- 매출 값을 색상 레이블에 올려둬서 색상에 따른 차이를 확인할 수 있음
```

### 워드 클라우드
```
- 문서 내에서 등장하는 키워드가 얼마나 자주 등장하는지를 텍스트 크기로 표현하여 직관적으로 시각화 가능
- 히트맵에서 표현된 단어들을 워드클라우드로 바꾸기 위해서는 마크에서 텍스트로 변환하면됨
```



## 22강: 이중축과 결합축
<!-- 이중축과 결합축에 관해 배우게 된 점을 적어주세요 -->
### 이중축
```
- 하나의 뷰 안에서 하나의 축을 이중으로 사용하는 차트(양쪽 측 분리 사용)
- 마크를 각각의 축에 개별적으로 사용할 수 있음
```

### 결합된 축
```
- 하나의 축을 공유하는 차트
- 축을 공유하는 측정값을 필요에 따라 추가할 수 있음 
- 필트를 왼쪽에 추가하면 결합된 축/ 오른쪽이면 이중축
```


## 23강: 분산형 차트
<!-- 분산형 차트에 관해 배우게 된 점을 적어주세요 -->
```
- 파라미터 간의 상관관계를 파악하는데 유용한 그래프
- 추세선을 활용하여 관계파악을 할 수 있음
- 범주에 상관없이 전체 추세를 확인하고 싶다면 시트에서 모든 추세선을 클릭한 뒤 요소에서 범주를 선택 취소 하면됨 
- 제품 별 추세선과 전체 추세선을 한 뷰에서 같이 보고 싶다면 이중축을 활용하면 됨 
```

```js
강의 영상과 달리, 우리 파일에는 '제조 업체' 필드가 없습니다. 필요한 경우, 계산된 필드를 이용해 'SPLIT([제품 이름], ' ', 1)'를 '제조 업체'로 정의하시고 세부 정보에 놓아주세요.
```



## 24강: 히스토그램
<!-- 히스토그램에 관해 배우게 된 점을 적어주세요 -->
```
- 분포 형태를 표시하는 차트
- 모양은 막대그래프와 비슷하지만, 연속형 측정값을 범위/구간 차원으로 그룹화한다는 점에서 차원이 있음 
- 차원 필드 없이 측정값 만으로 그래프를 그릴 때 주로 사용
- 구간 차원: 일정한 크기의 포켓을 만들어 그 안에 값을 담아 표현 시키기 위한 도구
    - 구간 차원 크기: 구간별로 담을 포켓의 크기
- 표현방식에서 히스토그램을 설정하면 자동으로 구간 차원 등의 작업들이 수행됨
- 히스토그램은 연속적 측정값을 통해 수치 데이터의 빈도를 표시하는 양적 데이터이고 형태는 막대와 막대 사이가 붙어있음
- 막대그래프는 불연속형 여러 범주의 데이터를 비교하기 위해 사용되고 막대와 막대 사이의 공백이 존재하는 형태로 되어있음 
```
